## 本包覆盖什么

- 180 条输入记录的监督表示消融及融合实验，随机种子 0、1、2。
- 126 条输入记录的回顾性主动学习模拟，七种表示、四种采样策略、随机种子 0–4，标签预算 10–60。
- 完整参考结果、每个种子的固定划分、CGCNN 预计算嵌入、化学先验文本、特征字典。
- 当前 Fig. 3 的绘图脚本与源数据，以及完整七种表示的数值重分析。

包中不包含整篇稿件、个人缓存、DFT 二进制输出、本机路径或第三方代码仓库。原始源文件未修改。DFT 原始标签生成、可选 CGCNN 从头训练及后续催化计算不属于已验证的运行范围。

## 怎么用

先解压压缩包，然后在包的根目录按 README 安装依赖。依次执行：

```bash
python scripts/verify_release.py
python scripts/reproduce.py --mode summary
python scripts/reproduce.py --mode smoke
```

前两条核查文件与重算参考数据，第三条执行小规模真实训练。`--mode supervised` 和 `--mode active-learning` 执行完整的新训练；完整训练没有在本次整理中全部重跑。新训练结果输出到 outputs，不覆盖历史参考结果。

## 与正文对齐的事项

1. Fig. 3a 是 180 条记录的监督实验，b–d 是 126 条记录的主动学习实验，不能写为同一套训练/测试实验，也不能替换成最终 185 条标签目录的样本量。
2. a 中化学先验文本由 TF-IDF/SVD 编码；b–d 使用的是数值化化学先验块。两种实现应在方法中分别交代。
3. 主图展示的是各指标下表现最差的单/双模态配置；完整配置结果都保留在包中。该选择规则不等于类别平均或最强基线比较。
4. 原代码中的残差权重选择并非各层都严格嵌套的 OOF 过程；最优变体还使用了已观测测试指标进行选取。包内保留原算法与这一边界。
5. 初始主动学习集合按回顾性已知标签分层，真实未来候选没有这些标签；当前代码的采样 RNG 规则也缺少历史版本对照。因此不得宣称已验证完全一致的历史训练复现。

这些事项完整记录在 REPRODUCIBILITY.md 中，避免代码包和论文方法彼此矛盾。
